# Lumigram - Instagram Clone

A full-stack mobile application built with React Native (Expo) and Firebase, featuring authentication, image sharing, favorites, and user profiles.

## Features

- 📱 Cross-platform (iOS, Android, Web)
- 🔐 Firebase Authentication (Email/Password)
- 🌓 Dark/Light theme toggle
- 📸 Image upload with captions
- ❤️ Double-tap to favorite posts
- 🔍 User search functionality
- 👤 User profiles with editable info
- 🔄 Infinite scroll with pagination
- 🔄 Pull to refresh
- 📱 Responsive design

## Prerequisites

- Node.js (v16 or newer)
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- Firebase account
- iOS Simulator (Mac only) or Android Studio for mobile development
- Web browser for web development
